# ELVION — bộ khung dự án

ELVION là trợ lý cá nhân điều khiển macOS bằng giọng nói, ưu tiên xử lý trên máy. Đây là dự án dài hạn, bắt đầu bằng một lõi chạy được và mở rộng dần sang lịch, nghiên cứu web, giao tiếp và thiết bị IoT.

## Đọc theo thứ tự

1. [PROJECT_PLAN.md](PROJECT_PLAN.md): mục tiêu, phạm vi và lộ trình.
2. [ARCHITECTURE.md](ARCHITECTURE.md): module, luồng dữ liệu và AIMS.
3. [API_CONTRACTS.md](API_CONTRACTS.md): hợp đồng dữ liệu nội bộ, adapter và quyền.
4. [TECH_STACK.md](TECH_STACK.md): lựa chọn công nghệ và nguyên tắc thay thế.
5. [CURRENT_TASKS.md](CURRENT_TASKS.md): backlog gần nhất, tiêu chí nghiệm thu.
6. [DECISIONS.md](DECISIONS.md): quyết định đã thống nhất và điểm còn mở.

Các ví dụ hợp đồng bên dưới là bản thiết kế ban đầu, chưa phải API đã triển khai. Cập nhật tài liệu hợp đồng trước khi đổi giao diện giữa các module.
