# Đánh giá ELVION

`scenarios/` chứa kịch bản nhỏ có thể công khai và tái lập.
Mỗi kịch bản cần nêu trạng thái ban đầu, tác vụ, quyền, hậu điều kiện và ngân sách bước/thời gian.
Kết quả, trace và dataset phát sinh lưu ngoài repo hoặc trong `artifacts/` đã ignore.
Trace thành công không tự động là nhãn đường tối ưu của AIMS;
cần so sánh phương thức trên cùng tình huống và tách train/test phù hợp.
